Frequency Distributions Slide 2

Section 2.1 · التوزيع التكراري للبيانات الوصفية

raw data data collected in its original form  →  organized  →  frequency distribution

Frequency distribution is the organizing of raw data in table form, using classes and frequencies.
💡 شرح مبسط
البيانات الخام تشبه كومة أوراق مبعثرة. جدول التوزيع التكراري يرتّبها في جدول من عمودين: الفئة (Class) والتكرار (Frequency)، أي: كم مرة ظهرت كل فئة؟

Qualitative data and its vocabulary

TermMeaning (from the lecture)
Qualitative dataNon-numerical; the value can be classified only into categories called classes.
ClassOne of the categories into which the data can be classified.
Class frequency (f)The number of observations falling into a particular class.
Class relative frequencyclass frequency ÷ total number of observations (n).
Class percentageclass relative frequency × 100.
class relative frequency = class frequencyn   ·   class percentage = (class relative frequency) × 100

Types of frequency distributions

Categorical frequency distributions

Used for data that can be placed in specific categories, such as nominal- or ordinal-level data. (هذه الشريحة)

Grouped frequency distributions

Used when the range of values is very large. The data are grouped into classes that are more than one unit in width. (الشريحة 5)

Relative Frequency and Percentage Slide 3

Section 2.1 · التكرار النسبي والنسبة المئوية

relative frequency = fn  ·  percentage = relative frequency × 100
💡 شرح مبسط
التكرار النسبي = "ما حصة هذه الفئة من الكل؟" وهو كسر بين 0 و1. إذا ضربناه في 100 صار نسبة مئوية. مثال: فئة تكرارها 5 من 25 → 5 ÷ 25 = 0.20 → 20%.
🧠 للحفظ
مجموع كل التكرارات النسبية = 1 دائمًا، ومجموع كل النسب المئوية = 100%. استخدمهما كاختبار ذاتي لحلّك.

Blood glucose levels (50 people) — grouped frequency distribution

Click a row to see its limits and boundaries.

Terms associated with a grouped frequency distribution

TermMeaningFirst class (58–64)
Class limitsThe smallest and largest data values that can be included in a class.58 and 64
Lower class limitThe smallest data value in the class.58
Upper class limitThe largest data value in the class.64
Class boundariesUsed to separate the classes so that there is no gap in the frequency distribution.57.5 – 64.5
Lower boundary = lower limit − 0.5   ·   Upper boundary = upper limit + 0.5
💡 شرح مبسط
لو كانت البيانات أعدادًا صحيحة فهناك "فجوة" بين 64 و65 (حيث ينتهي صف ويبدأ التالي). الحدود الفعلية (Boundaries) تسدّ هذه الفجوة بوضع الفاصل في المنتصف: 64.5. لذلك نطرح 0.5 من الحد الأدنى ونضيف 0.5 إلى الحد الأعلى. (العرض الفعلي لكل فئة هنا = 64.5 − 57.5 = 7.)
➕ إضافة (ليست في الشرائح الأصلية): عرض الفئة (class width) = الفرق بين الحدين الفعليين للفئة، وهنا 7 لكل الفئات.

Graphical descriptive methods for quantitative data: Dot plot Stem-and-leaf display Histogram

1. Dot plot (مخطط النقاط)

A dotplot is a statistical graph in which each data value is plotted as a point (dot) above the horizontal axis. If a value occurs more than once, the dots are plotted above one another.

Dotplots show how the data are distributed and whether there are any extremely high or low values — called outliers.

Example — named storms per year (last 40 years)

Dot plot — click a dot

Detecting Outliers: Box Plots and z-Scores Slide 13
Section 2.7 · اكتشاف القيم الشاذة: مخطط الصندوق والدرجة المعيارية
An outlier is an observation (measurement) that is unusually large or small relative to the other values in a data set.
Outliers are typically attributable to one of the following causes:
  1. The measurement is observed, recorded, or entered into the computer incorrectly.
  2. The measurement comes from a different population.
  3. The measurement is correct but represents a rare (chance) event.
Two useful methods for detecting outliers: 1. Graphical: box plots 2. Numerical: z-scores
💡 شرح مبسط
القيمة الشاذة هي قيمة "غريبة" بعيدة عن بقية البيانات. قد تكون خطأ إدخال (مثل كتابة 500 بدل 50)، أو من مجتمع مختلف، أو حدثًا نادرًا لكنه صحيح. لا نحذفها مباشرة؛ نكتشفها أولًا ثم نبحث عن سببها.
Box plot (مخطط الصندوق)
Procedure for constructing a box plot:
1. Find the five-number summary (min, Q1, median, Q3, max).
2. Draw a horizontal axis with a scale that includes the maximum and minimum data values.
3. Draw a box whose vertical sides go through Q1 and Q3, and draw a vertical line through the median.
4. Draw a line from the minimum value to the left side of the box and a line from the maximum value to the right side of the box.
💡 شرح مبسط
الصندوق يحتوي على 50% من البيانات الوسطى (من Q1 إلى Q3)، والخط داخله هو الوسيط، والعارضتان تمتدان إلى أصغر وأكبر قيمة. وطول الصندوق = المدى الربيعي IQR = Q3 − Q1.
Right-skewed (+ve) and left-skewed (−ve) box plots
Right skewed (+ve skewed): long right whisker
Left skewed (−ve skewed): long left whisker

1. Check the outliers using a box plot (the IQR rule)
Procedure for identifying outliers:
Step 1: Arrange the data in order and find Q1 and Q3.
Step 2: Find the interquartile range IQR = Q3 − Q1.
Step 3: Multiply the IQR by 1.5.
Step 4: Subtract the value from step 3 from Q1, and add it to Q3.
Step 5: Any data value smaller than Q1 − 1.5(IQR) or larger than Q3 + 1.5(IQR) is an outlier.
💡 شرح مبسط
الحاجز (fence) = حدّ مسموح به. الحاجز الأدنى = Q1 − 1.5×IQR، والحاجز الأعلى = Q3 + 1.5×IQR. أي قيمة خارج المجال بين الحاجزين فهي قيمة شاذة.
