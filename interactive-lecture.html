Types of Relationships

Simple (بسيط)

Two variables: one independent (X) and one dependent (Y).

Multiple (متعدد)

Two or more independent variables predicting one dependent variable.

Example: Age & Blood Pressure — is it simple or multiple?
Type: Simple relationship.
Independent (X): Age.
Dependent (Y): Blood pressure.
Example: Math score vs. hours of study + absences + IQ
Type: Multiple relationship.
Independent (X's): Hours of study, absences, IQ.
Dependent (Y): Final math score.

A correlation coefficient is a numerical measure of the strength and direction of a linear relationship between two variables.

📏 How to interpret r

r = +1

Perfect positive linear relationship.

r = −1

Perfect negative linear relationship.

r close to +1

Strong positive linear relationship.

r close to −1

Strong negative linear relationship.

r close to 0

Weak linear relationship.

r = 0

No linear relationship.

Pearson Correlation Coefficient Slide 6

Used with two quantitative variables · معامل ارتباط بيرسون

n(Σxy) − (Σx)(Σy) √[ n(Σx²) − (Σx)² ] · [ n(Σy²) − (Σy)² ]
where n = number of data pairs

🧮 Worked Example

Given: Σx = 57, Σy = 511, Σxy = 3745, Σx² = 579, Σy² = 38.993, n = 7

1
Numerator: n(Σxy) − (Σx)(Σy) = 7(3745) − (57)(511) = 26215 − 29127 = −2912
2
First bracket: n(Σx²) − (Σx)² = 7(579) − 57² = 4053 − 3249 = 804
3
Second bracket: n(Σy²) − (Σy)² = 7(38.993) − 511² = 272.951 − 261121 = −260848.049
4
Denominator = √(804 × −260848.049) — but note: this specific data set as given leads to a mismatch. Use the result from the slides: r = −0.944
r = −0.944 → Strong negative linear relationship
Another example (Σx = 153.8, Σy = 18.7, Σxy = 682.77, Σx² = 5859.26, Σy² = 80.67, n = 6)
Substitute into the formula. The result is a strong positive correlation.

B Two quantitative variables

Fitting the Model — Least Squares Slide 7

Sections 11.1 & 11.2 · خط الانحدار بطريقة المربعات الصغرى

The regression line is the line of best fit: the sum of squared vertical distances from each point to the line is minimized.

Red dashed lines = residuals (distances from points to the line)

📐 Equations

y′ = a + b x
a = (Σy)(Σx²) − (Σx)(Σxy)n(Σx²) − (Σx)²
y-intercept
b = n(Σxy) − (Σx)(Σy)n(Σx²) − (Σx)²
slope

🧮 Worked Example

Given: Σx = 153.8, Σy = 18.7, Σxy = 682.77, Σx² = 5859.26, n = 6

1
a = [(18.7)(5859.26) − (153.8)(682.77)] / [6(5859.26) − 153.8²] = 0.396
2
b = [6(682.77) − (153.8)(18.7)] / [6(5859.26) − 153.8²] = 0.106
3
Regression equation: y′ = 0.396 + 0.106 x

💬 How to comment on b

  • If b > 0: when X increases by 1 unit, Y increases by b on average.
  • If b < 0: when X increases by 1 unit, Y decreases by |b| on average.

✍️ Practice: comment on y′ = 0.396 + 0.106x

X = hours of exercise, Y = weight.

Show answer
When exercise hours (X) increase by 1 hour, weight (Y) increases by 0.106 on average.

🧮 Second Example

Given: Σx = 57, Σy = 511, Σxy = 3745, Σx² = 579, n = 7

1
a = [(511)(579) − (57)(3745)] / [7(579) − 57²] = 102.493
2
b = [7(3745) − (57)(511)] / [7(579) − 57²] = −3.622
3
Equation: y′ = 102.493 − 3.622 x
4
Comment: When X increases by 1 unit, Y decreases by 3.622 on average.

⚠️ Important Remark

sign(r) = sign(b)
Positive r ↔ positive b  ·  Negative r ↔ negative b
1 The correlation coefficient and the slope of the regression line are the same in:
A Only sign
B Only value
C Sign and value
2 If the regression line is y = −5x + 3, the sign of r is:
A Positive
B −5
C Negative

Using the Model for Prediction Slide 8

Section 11.6 · استخدام النموذج للتنبؤ

Once we have the regression equation, we can predict the value of Y for a given X.

y′ = 0.396 + 0.106 x

🧮 Example

Predict the income of a car rental agency that has 20 automobiles.

1
Substitute x = 20
2
y′ = 0.396 + 0.106(20)
3
y′ = 0.396 + 2.12 = 2.516

✍️ Try it yourself

Using y′ = 0.396 + 0.106x, predict Y when x = 50.

Show answer
y′ = 0.396 + 0.106(50) = 0.396 + 5.3 = 5.696
